# Decor Republic

Static rebuild of the public Decor Republic website for GitHub Pages. The HTML, CSS and JavaScript can be served directly without a build step.

- Uses the original public page routes, project galleries, articles, and studio information. Earlier GitHub preview addresses forward to the matching rebuilt pages.
- There is one enquiry form on the home page. It uses FormSubmit for info@decor-republic.com. Confirm the recipient with FormSubmit and check delivery before sending visitors to the new site.
- Appointment requests use that enquiry form. The home design toolkit's checkout route directs customers to the studio.
- The GitHub preview uses the original image URLs on Wix's public media CDN. The separate backup includes copies in its media directory. Both versions load the original Brandon Grotesque webfont from its public font URL and Cormorant Garamond from Google Fonts.

Serve the directory over HTTP to preview the site locally.
